# Your ambient tracks

Drop `ambient1.mp3`, `ambient2.mp3`, … into this folder. `.ogg`, `.wav`, and `.m4a` also work.
The Vite plugin discovers them automatically on the next dev-server start or production build.
ASADCORE picks a random track, avoids the previous track using localStorage, and crossfades tracks.
With no files here, the built-in generative Web Audio engine creates a new calm soundtrack every visit.
You own or must have permission to use any files you add. Keep web tracks reasonably compressed.
